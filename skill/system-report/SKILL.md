# 系统体检报告

## 目标
产出一份结构化的中文体检报告，覆盖：系统与硬件概要、开发环境、磁盘空间、正在运行的重点进程。

## 执行步骤
1. **一次收集，不要碎步**。用**单个** `run_command` 并行收集信息（Windows 用 `cmd` 语法）：
   ```
   ver & wmic cpu get name & wmic computersystem get TotalPhysicalMemory & wmic logicaldisk get caption,freespace,size & node -v & npm -v & python --version
   ```
   若 `wmic` 不可用，改用 PowerShell 读取同样信息。
2. 需要进程信息时再单独执行一次 `tasklist`，只在输出中筛出：node、python、java、docker、mysql、redis、nginx、chrome、msedge 等关键字，不要整表转述。
3. 磁盘容量把 字节 换算成 GB（保留 1 位小数），并算出每条磁盘剩余百分比。
4. 任何命令失败或超时，如实写出"该项获取失败"及原因，**不要编造数值**。

## 输出格式
```
# 系统体检报告

## 概览
- 系统 / CPU / 内存：…

## 开发环境
| 组件 | 版本 | 状态 |
|---|---|---|

## 磁盘
| 盘符 | 总容量 | 可用 | 可用率 |
|---|---|---|---|

## 运行中的关键进程
- 进程名 ×数量（用途推测）

## 建议
- 2~4 条基于实测数据的可执行建议（例如可用空间低于 15% 的盘建议清理）
```

## 注意
- 只做只读收集，不执行任何清理或修改操作；若要清理，先给出清单并等用户确认。
- 报告中不写入任何用户隐私路径或凭据内容。
